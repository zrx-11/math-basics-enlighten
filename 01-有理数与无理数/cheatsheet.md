# 速查表

## 公式 / 规则 / 结论
| 场景 | 内容 |
|---|---|
| 有理数的判据 | 能写成 m/n（m∈Z，n∈N+）；有限小数与循环小数都满足 |
| 负数比较大小 | 绝对值大的反而小；通分后比较分子 |
| 减法与除法 | a−b=a+(−b)；a÷b=a×(1/b)，b≠0 |
| 符号规则来源 | 由分配律推出 (−a)(−b)=ab，不是额外规定 |
| 零指数与负指数 | a^0=1（a≠0）；a^−n=1/a^n |
| 算术根 | ⁿ√a≥0；方程 x^n=a（n 偶，a>0）有两根 ±ⁿ√a |
| √2 无理性 | 假设 √2=m/n 最简 → m²=2n² → m、n 皆偶 → 矛盾 |
| 截断误差 | |√2−x_n|<10^−n；要误差 <ε 取 n>−lg ε |
