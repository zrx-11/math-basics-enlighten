# 《数学基础知识丛书》点化学习系统

线上：https://zrx-11.github.io/math-basics-enlighten/ ｜ 仓库：https://github.com/zrx-11/math-basics-enlighten

24 本扫描版数学读物，做成一套可以开学的东西：一个总入口 `index.html`，每本书一份 Markdown 知识库、一份单书学习伴侣 HTML，外加一份「从零推导」交互页。

## 界面能力（知枢规范）

- **KaTeX 公式**：`$…$` 与 `$$…$$` 走 KaTeX 渲染，CDN 顺序 npmmirror → jsdelivr → unpkg。
- **指数上标**：正文里用 `a^n`、`a^{m+n}`、`a^(m+n)`、`a^-n` 写的指数，构建时统一转成 `<sup>` 真上标（此前会原样显示成 `a^n`）。Mermaid 图内的标签改写成 Unicode 上标（ⁿ、ᵐ），因为图内不支持 HTML。
- **诊断倒推**：侧边栏「🩺 诊断测试」随机出题，答错沿 `prerequisites` 链倒推根因并给出跳转。
- **深度推导折叠**：每章、每个概念页底部有 `<details>` 折叠的「从零推导」，默认收起。
- **出处脚注**：章页顶部显示「📖 出处：原书 PDF」。
- **前置知识条**：章页顶部显示「⬅ 前置：第 N 章」，可直接点过去。
- **知识图谱**：`#/book/<slug>/graph` 力导向图，节点是章节与概念，点击跳转。

## 怎么用

1. 双击 `index.html`（单文件，离线可开，不需要联网，也不需要起服务器）。
2. 顶部切换总览与 24 本书；左侧是学习路径 / 章节 / 概念 / 测验 / 抽认卡 / 术语 / 模式 / 速查。
3. 每本书建议按这个顺序走：**先点右上角「📐 从零推导」把公式自己推一遍 → 再回左侧「学习路径」按章节读 → 做章节测验 → 过抽认卡**。
4. 进度、测验成绩、卡片复习状态存在浏览器本地（localStorage），刷新和关掉浏览器都不丢；换浏览器或清缓存会重置。

单独把某一本发给别人：打开该书目录下的 `NN-书名/<slug>学习伴侣.html`，同样离线可用。只想看推导：`NN-书名/<slug>从零推导.html`。

## 部署到 GitHub Pages

```bash
# 1. 在仓库根目录放好本包全部文件（index.html 必须在根）
git add -A
git commit -m "点化学习系统：数学基础知识丛书 24 本"
git push origin main

# 2. 仓库 Settings → Pages → Source: Deploy from a branch
#    Branch: main   Folder: / (root)   → Save
```

等待 1–2 分钟后访问 `https://<用户名>.github.io/<仓库名>/`。

几点注意：

- `.nojekyll` 必须在根目录。没有它，Jekyll 会跳过以 `_` 开头的目录（`_build/`、`_work/`），而且中文文件名处理也可能出问题。
- 一切路径都是相对路径，子目录部署（`/repo/`）与根部署都能正常打开。
- 页面本身不依赖外网；只有 Mermaid 图会尝试从 CDN 加载渲染库，离线时自动降级为源码展示 + 说明文字，不影响阅读。
- 如果想公开仓库，建议先删掉 `_work/` 与 `_build/`：它们不影响站点运行，但包含原书扫描页截图，版权边界需要自己判断。

## 已知限制

- 原书是扫描版，没有文字层。抽取走 OCR，中文正文可用，但公式与上下标会缺失、错位。因此**所有精讲内容都是按原书结构重写的**，不是 OCR 文本的复制；公式、例题的数值都重新核对并自己算过一遍。
- OCR 原文仅作过程留档（`_work/raw/full.txt`），不作为内容依据，也不保证覆盖全部 24 本（见 `交付说明.md` 的覆盖说明）。
- 推导页把 KaTeX 的 CSS、JS 与 20 个 woff2 字体全部 base64 内联，单页约 645–653 KB；24 页合计约 15.5 MB。这是为了 `file://` 下双击即用，不是冗余。
- 单书伴侣与总入口的 Mermaid 图、KaTeX 公式、知识图谱（vis-network）都需要联网加载；完全离线时 Mermaid 降级为源码、公式显示 LaTeX 源码、图谱显示加载失败提示，正文与导航不受影响。
